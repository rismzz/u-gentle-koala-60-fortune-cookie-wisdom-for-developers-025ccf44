A deterministic program that writes one original fortune-cookie line for a software developer to `/output/entry.txt` — your code will compile on the first try; unfortunately, it will be someone else's code. No network, no randomness, no model call: the same 87 characters on every run.

## Run it

```sh
python3 main.py
```
